# Android: общий интерфейс WatchNext

Оболочка открывает веб на вашем сервере. Поиск раздач, фильмографии, подборки,
случайный выбор, история просмотренного, очередь и настройки используют ту же
реализацию и API, что браузер. После обновления сервера новый интерфейс доступен
без переустановки APK. Без работающего сервера приложение показывает ошибку связи.

Первый запуск предлагает адрес веба. Если установлен прежний native-клиент,
читается его DataStore `watchnext_settings/server_url`: стандартный API-порт 8000
меняется на веб-порт 8787; адрес можно изменить перед подключением. Свои порты
укажите вручную. Пароли qBittorrent/Jellyfin и старые локальные лимиты в веб не
переносятся: лимиты читаются с сервера. При защищённом API токен вводится в
веб-настройках и хранится только до закрытия процесса, как сессия браузера.

Кнопка «Сервер» всегда доступна для смены адреса и восстановления подключения.
WebView сохраняет DOM storage/cookies; обновление APK и образов сервера их не
очищает. Данные разных веб-адресов относятся к разным origins, но лимиты и
история общие на сервере. Внешние ссылки и Jellyfin открываются отдельным
приложением. Импорт использует системный выбор документов, экспорт JSON —
системное «Сохранить как», без разрешения на всё хранилище. Входящие magnet-ссылки
открывают форму подтверждения, не запускают загрузку автоматически.

## Сборка

Нужны JDK 21+ для тестов Android 36, Android SDK 36.1 и build-tools.

```sh
cd android
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

Для установки поверх предыдущего APK **обязательны та же подпись и applicationId**.
ApplicationId сохранён: `com.aistudio.watchnext.kzrqx`, versionCode повышен до 2.
Прежний локальный debug-ключ можно передать через `WATCHNEXT_KEYSTORE`.
Для release задайте `WATCHNEXT_KEYSTORE`, `WATCHNEXT_STORE_PASSWORD`,
`WATCHNEXT_KEY_ALIAS`, `WATCHNEXT_KEY_PASSWORD`. Ключей и APK в Git нет.
Не удаляйте приложение перед обновлением: удаление Android очищает его данные.

## Проверки

`WebShellTest` проверяет перенос адреса, границы origin, запрет file://,
сохранение адреса при повторном запуске и обязательные WebView-настройки.
TLS-ошибки не обходятся; JS bridge и доступ к произвольным локальным файлам
не включены. Интерфейс загружается только с выбранного пользователем origin.
