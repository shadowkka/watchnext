# Проверки первой версии

Проверено 21 октября 2026 года.

- 199 автоматических тестов Python: очередь, удаление, лимиты, семейный доступ, поиск, фильтры, подписки и установщик.
- Синтаксис обоих shell-скриптов.
- Docker Compose с нестандартными портами и отдельной DNS-подсетью.
- Первичная настройка выделенных qBittorrent 5.2.4 и Jellyfin 12.2, авторизация, создание двух библиотек и API-ключа.
- Повтор настройки без смены паролей, дублирования библиотек и API-ключей.
- Жёсткая ссылка между папками загрузки и библиотеки.
- Настройка новых Jackett 0.24.2887, FlareSolverr 3.5.2 и RuTor.
- Проверка опубликованного набора файлов на отсутствие личных идентификаторов, конфигураций, состояния, ключей и совпадений с рабочими секретами.

Проверки реальных сервисов выполнялись в отдельном Docker project с другими портами и собственной папкой данных. Временные контейнеры и сети удалены после проверки. Рабочие сервисы не перенастраивались.

Полный интерактивный диалог Telegram и вход RuTracker требуют действий владельца; их нельзя автоматически завершить без отдельного бота и учётной записи трекера. Установка Docker через apt проверена по официальной инструкции и синтаксису; на тестовой машине Docker уже был установлен. Аппаратное перекодирование и конкретные модели телевизоров не проверялись.
