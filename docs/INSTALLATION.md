# Установка

## Требования

Проверяемая конфигурация — Ubuntu 22.04/24.04 x86-64 с Python 3, Docker Engine и плагином Compose. Нужен обычный пользователь с `sudo` или доступом к Docker. Сервис рассчитан на небольшой домашний сервер; FlareSolverr ограничен 1 ГБ RAM, Jellyfin и qBittorrent требуют дополнительную память. Аппаратное перекодирование не настроено.

Папки `downloads`, `library`, `movies` должны быть на одном диске/разделе. Диск должен поддерживать жёсткие ссылки: обычные локальные ext4/xfs подходят; сетевые/съёмные файловые системы требуют проверки. При выборе новой папки установщик проверяет общий device ID.

## Пошаговый установщик

```bash
git clone https://github.com/shadowkka/watchnext.git
cd watchnext
bash install.sh
```

Не запускай `sudo bash install.sh`: файлы конфигурации должны принадлежать обычному пользователю. По необходимости установщик вызовет `sudo docker`.

Если Docker отсутствует, предлагается установка из официального apt-репозитория. Можно выполнить её отдельно:

```bash
bash scripts/install-docker-ubuntu.sh
```

Помощник не удаляет конфликтующие старые пакеты и не обновляет уже установленный Docker. Если есть другая установка Docker/containerd, сначала проверь [официальную инструкцию](https://docs.docker.com/engine/install/ubuntu/).

Предварительная проверка без запуска сервисов:

```bash
bash install.sh --check
```

### Ответы на вопросы

- **IP:** адрес интерфейса домашней сети. `127.0.0.1` ограничит доступ самим сервером/SSH-туннелем; телевизор напрямую не подключится.
- **Папка видео:** абсолютный путь к диску с нужным объёмом. Например, `/mnt/media/watchnext`.
- **Порты:** 8080 — qBittorrent, 8096 — Jellyfin, 9117 — Jackett, 6881 TCP/UDP — BitTorrent. Если они заняты, выбери другие. Установщик не отключает уже работающие сервисы ради освобождения порта.
- **Jellyfin:** общий профиль просмотра и удобный пароль для телевизора. Enter генерирует пароль и сохраняет его в `access.txt`.
- **Telegram:** отдельный бот без webhook и другого потребителя `getUpdates`. Отправь ему `/start`, затем выбери свой аккаунт из списка.
- **Лимиты:** число непросмотренных серий, общий объём фильмов/серий и резерв свободного места.

Установка может быть продолжена после сбоя тем же `bash install.sh`. Секреты сохраняются локально до настройки сервисов. Повторный запуск после успешной установки не меняет пароли, очередь и библиотеки.

## Ручная установка

Если автоматическая настройка не подходит:

1. Выполни `python3 prepare.py`; укажи IP.
2. Настрой `.env`, проверь порты и `DATA_DIR`.
3. Запусти `docker compose up -d qbittorrent jellyfin dnsproxy flaresolverr jackett`.
4. Открой qBittorrent. Получи его временный пароль в локальных логах, задай постоянный и запиши `QBIT_PASSWORD` в `.env`. Не публикуй логи с временным паролем.
5. Пройди мастер Jellyfin, создай общий профиль. Добавь «Сериалы» → `/data/library`, «Фильмы» → `/data/movies`. Создай API-ключ и запиши `JELLYFIN_USERNAME`, `JELLYFIN_API_KEY` в `.env`.
6. Выполни `python3 setup_telegram.py`, введи токен и выбери свой ID.
7. Скопируй API Key из Jackett в `JACKETT_API_KEY` в `.env`. Настрой индексаторы.
8. Запусти `docker compose up -d --build queue`.

Ручной путь не создаёт `state/installation-complete.json`. Не запускай поверх него мастер автоматической первичной установки: используй обычные команды Compose.

## Jackett, RuTracker и DNS

В Jackett укажи FlareSolverr URL `http://flaresolverr:8191`, timeout 55000 мс. FlareSolverr и DNS-прокси не публикуют порты на хосте.

RuTor не требует логина. RuTracker требует твоей учётной записи; введи её непосредственно в Jackett. Отключи **Strip Russian Letters** для сохранения русских названий и озвучек. CAPTCHA вводится человеком. FlareSolverr может помочь с браузерной проверкой, но не гарантирует прохождения любой защиты.

Для Jackett и FlareSolverr используется DNS по HTTPS через `adguard/dnsproxy`. Установщик выбирает подсеть, не пересекающуюся с известными Docker-сетями. При ручной установке проверь `SEARCH_DNS_SUBNET` и `SEARCH_DNS_IP` в `.env`; меняй их согласованно. Это не настраивает обход сетевых ограничений, VPN и прокси.

Для календаря подписок нужен доступ **с сервера и из контейнера queue** к `https://api.tvmaze.com:443`. При необходимости настрой маршрутизацию своего VPN. Веб-доступ с телефона сам по себе не доказывает доступ контейнера.

## Клиенты Jellyfin

Используй [официальный клиент](https://jellyfin.org/clients/). На всех устройствах входи под общим профилем: его история запускает освобождение места. Quick Connect можно включить в Jellyfin, чтобы подтверждать вход телевизора с другого устройства.
