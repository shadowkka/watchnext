# Эксплуатация

Команды выполняются из папки проекта. Если Docker доступен только через `sudo`, добавь `sudo` перед `docker`.

## Запуск, остановка, диагностика

```bash
docker compose up -d
docker compose ps
docker compose logs --tail=100 queue
docker compose stop
```

`/pause` в боте останавливает выбор загрузок и удаление, но оставляет бот доступным. `docker compose stop` останавливает сами сервисы.

## Резервная копия

Останови сервисы на время согласованной копии:

```bash
docker compose stop
mkdir -p backups
chmod 700 backups
tar -czf backups/watchnext-config.tar.gz .env access.txt state config
chmod 600 backups/watchnext-config.tar.gz
docker compose start
```

Резервная копия содержит секреты, историю и приглашения. Храни её приватно, не добавляй в GitHub и не отправляй вместе с диагностикой. Если `access.txt` нет при ручной установке, исключи его из команды.

Видео из `DATA_DIR` копируется отдельно. Сохраняй структуру и hardlink при резервировании файлов; при обычном копировании ссылка может стать второй копией. Для восстановления нужны согласованные `state`, настройки сервисов и сами файлы.

## Обновление

Сначала сделай резервную копию и прочитай изменения релиза. Если меняешь major/minor Jellyfin, учитывай миграции его базы и совместимость отката.

```bash
docker compose stop queue
git pull --ff-only
docker compose build queue
docker compose up -d --no-deps queue
docker compose ps
```

Эта последовательность обновляет worker; не обновляет автоматически контейнеры Jellyfin/qBittorrent/Jackett. Их версии задаются Compose. Изменение образа сервиса требует отдельного `docker compose up -d ИМЯ_СЕРВИСА` после резервирования.

Не запускай установщик как средство обновления и не заменяй `.env`/`state` примерами из репозитория.

## Удаление

Остановить и удалить контейнеры/сети проекта:

```bash
docker compose down
```

Эта команда сохраняет bind mount папки с видео, настройками и состоянием. Удаление этих папок — отдельное решение владельца; автоматического стирания установщик не делает. Docker, другие проекты и TorrServer не удаляются.

## Что хранится локально

| Путь | Содержимое |
| --- | --- |
| `.env` | токен Telegram, API-ключи, параметры подключения |
| `access.txt` | локальные логины/пароли после автоматической установки |
| `config/` | базы и настройки qBittorrent/Jellyfin/Jackett, включая учётные данные трекеров |
| `state/state.json` | очередь, история обработки, приглашения, кнопки, поиски и подписки |
| `state/torrents/` | метаданные torrent для повторного добавления |
| `cache/` | кеш Jellyfin |
| `DATA_DIR` | исходники и hardlink публикаций |

Все эти данные исключены из Git. Проект не отправляет их разработчику; настроенные внешние сервисы получают необходимые рабочие запросы: Telegram — сообщения, трекеры/Jackett — поисковые запросы, TVmaze — названия и ID сериалов, провайдеры Jellyfin — запросы метаданных.
