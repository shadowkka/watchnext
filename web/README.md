# WatchNext Web

Локальный адаптивный интерфейс на Node.js 22 без npm-зависимостей. Устанавливается вместе с сервером из корневого `compose.yaml`. [Установка и интеграции](../docs/WEB.md).

## Возможности

- Очередь, эпизоды, лимиты и подписки.
- Поиск раздач, сезоны с диапазонами, качество, озвучка и сортировка по размеру.
- Поиск → Что посмотреть: подсказки персон, фильмографии Wikidata, редакционные и наградные подборки, популярное.
- Поиск → Случайный: удалённый подбор TMDB по годам, жанру, стране и рейтингу; несколько вариантов и исключения.
- Импорт просмотренного CSV/JSON с IMDb/TMDB/Кинопоиск ID либо названием и годом; экспорт JSON. Список «Буду смотреть» импортировать не следует. Импорт профиля Кинопоиска по ссылке не реализован.
- Метаданные и обложки следующих 12 готовятся в фоне. «Показать ещё 12» всегда активно; незавершённые загрузки продолжаются на месте.
- Токены TMDB и Telegram настраиваются в интерфейсе. Кнопки перехода в Jellyfin открывают сериал, фильм или конкретную серию.
- На десктопе боковая навигация и сетки карточек; на телефоне нижняя навигация и одна колонка.

## Данные

TMDB запрашивается на сервере с русским языком. Резервные источники: Wikipedia/Wikidata, TVmaze и Cinemeta. В источниках возможны пропуски. Популярные подборки Cinemeta обновляются при следующем открытии после 6 часов кеша. Редакционные подборки привязаны к указанным публикациям; источники доступны в интерфейсе.

Случайный подбор запрашивает TMDB discover/movie, а не локальный каталог. Сэмплируются разные страницы; при более 500 страницах выбирается год в диапазоне. Равная вероятность всем фильмам мира не гарантируется. История, ранее показанные ID и дополнительные исключения проверяются до выдачи. Оценка TMDB подписана отдельно от IMDb.

`web-data/picker/watched.json` — история, `cards.json` — кеш карточек (до 1000), `posters/` — обложки. История не удаляется при очистке кеша. Данные и секреты не входят в исходники.

## Разработка

```sh
API_BASE=http://localhost:8000 PICKER_DATA_DIR=/tmp/watchnext-preview/picker WEB_SETTINGS_FILE=/tmp/watchnext-preview/settings.json PORT=18878 node server.mjs
npm test
npm run check
```

Шлюз проксирует разрешённые API-маршруты и отклоняет сторонний Origin. API_BASE и опциональный API_TOKEN задаются сервером. Настройки TMDB сохраняются в WEB_SETTINGS_FILE; переменная TMDB_READ_TOKEN поддерживается для старых установок до первого сохранения токена через интерфейс. Облачного размещения не требуется.
